## How it works

`main.py` holds the error message as a constant, validates it (non-empty, single
line, 1–200 characters, no leading or trailing whitespace), and writes it to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).

Run it locally:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/appliance-error-output python3 main.py
cat /tmp/appliance-error-output/entry.txt
```
